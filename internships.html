Data Science Internship · IDX Exchange

Building and validating machine learning models for residential property valuation.

The Problem

Real estate evaluation processes often struggle to scale effectively when transitioning from raw MLS data feeds to accurate close price predictions. For internal teams and clients at IDX Exchange, the objective was to create a data pipeline that accurately extracts key variables—such as total living area and lot size—and leverages them to project property values across the California market. The target was to ensure end-to-end auditability from initial data ingestion down to final performance metrics.

What I Did

Working within a structured remote data science team, I designed and deployed scalable machine learning models, specifically utilizing Linear Regression and Gradient Boosting frameworks. Rather than treating the cumulative codebase as a black box, I engineered preprocessing and feature-engineering pipelines from scratch in Python to clean raw MLS datasets. I systematically tracked model performance using key regression metrics, including median absolute percentage error (MdAPE) and R² coefficients.

What Came of It

The analytical pipelines significantly stabilized data accuracy, providing internal stakeholders with clear, data-driven insights. I packaged the final regression models and metrics into clean visual dashboards and comprehensive presentations to back high-level strategic planning. The entire repository was successfully managed under Git version control, maintaining strict continuity for our shared collaborative environment.

Backend AI Engineering Internship · FlyRank AI

Engineering scalable server-side AI workflows and evaluation frameworks.

The Problem

Automating large-scale organic and AI-discovery content pipelines introduces high risks of model hallucinations and system instability. For FlyRank, operating within the 10x.ai growth ecosystem, the challenge was to ensure that automated server-side models strictly grounded their outputs and maintained bulletproof uptime under heavy loads.

What I Did

I architected production-ready server-side AI workflows, focusing heavily on retrieval-augmented generation (RAG) architectures and structured output pipelines. To guarantee seamless integration with existing services, I built strict API contracts and automated tool-calling workflows. Crucially, I designed custom evaluation harnesses to explicitly calculate grounding accuracy and flag hallucination risks. I also implemented rigorous error-handling and validation blocks to prevent systemic downstream failures.

What Came of It

The resulting AI infrastructure achieved structural stability, allowing automated content generation to proceed safely with an explicit audit trail. By enforcing rigorous verification logic at the API layer, model outputs consistently matched the backend specifications, preventing malformed payloads from breaking downstream applications.
